*   **Check Disk Health:** Ensure your drive has no errors. Slow hardware can prolong the time it takes for the model to generate a full response.
*   **Update Graphics Drivers:** Visit your graphics card manufacturer website to find the newest drivers. Updated drivers allow the software to communicate better with your hardware.

## ❓ Frequently Asked Questions

**Why does the model take time to start?**
The model file is very large. It must copy itself from your hard drive into your system memory before it can answer your first question. This initial wait is normal for files of this size.

**Can I use this without an internet connection?**
Yes. Once you finish the download and installation, you do not need the internet to generate text. The software runs entirely on your local machine.

**The window says it is not responding, should I close it?**
Do not close the window during the loading process. Sometimes, the computer appears busy while it prepares the model. Wait at least three minutes for the window to become active before you assume an error occurred.

**Where does the model save my chat history?**
The software saves your chats in a folder inside the Documents directory on your computer. You can back up or move these files if you need to transfer your data to a different machine.
